LIVE DISCORD STATUS (optional, but cool)
----------------------------------------------------------------

The Discord card on the Connect section + the "Discord" row in
the System Stats panel can show your live Discord status
(ONLINE / IDLE / DO NOT DISTURB / OFFLINE) and what you're
streaming / playing / listening to. No server required — it
uses Lanyard's free public API.

ONE-TIME SETUP:

  1. With your Discord account, join the Lanyard server:
        https://discord.gg/lanyard
     (You don't have to participate — Lanyard just needs to see
      your account in a server it's in. You can mute it.)

  2. Find your Discord User ID (the 18-ish-digit number):
        Discord → Settings → Advanced → enable Developer Mode
        Right-click your name anywhere → "Copy User ID"

  3. In index.html, find:
        const DISCORD_USER_ID = 'DISCORD_USER_ID_HERE';
     Replace 'DISCORD_USER_ID_HERE' with your numeric ID, e.g.:
        const DISCORD_USER_ID = '123456789012345678';

  4. Save. The site will start polling Lanyard every 30 seconds.

Once configured:
  • A live status pill appears in the top-right of the Discord
    card (green/yellow/red/gray).
  • If you're streaming, playing a game, or listening to
    Spotify, that activity shows under the description.
  • The "Discord" row in the SYSTEM STATS panel updates too.

If Lanyard is ever down, the script silently does nothing — the
site keeps working fine.
